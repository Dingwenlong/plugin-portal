# Plugin Portal 胶囊真实色散补充设计

## 范围

本补充仅强化插件页浮动胶囊的光学色散，不改变 Header 尺寸、菜单位置、主题、滚动显隐、路由、插件资料或服务器 API。

## 光学表现

真实页面背景继续由 SVG 位移图折射，红、绿、蓝三通道采用轻微不同的位移量，在经过高对比文字时形成随背景内容变化的彩色边缘。增强折射可见度，但不增加静态五彩描边，中心阅读区也不增加彩色覆盖。

色散只存在于真实折射层，位于导航前景下方，不参与布局或交互。玻璃层不使用额外的 `filter` 或 `mix-blend-mode`，避免形成新的 backdrop root 而使背景折射失效。减少动态效果及折射降级状态不伪造光谱边，没有持续动画或远端资源。

## 验收

组件测试确认没有静态光谱描边，并保留三通道位移。Chromium 以启用和关闭真实折射的截图验证边缘发生可测背景位移，同时确认前景几何不变；深浅主题及 320px 布局均需无横向溢出。最右侧三角按钮不显示独立边框，键盘焦点以图标光晕提示。
