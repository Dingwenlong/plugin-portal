# Plugin Portal 玻璃胶囊立体层次补充设计

## 适用范围

本补充设计在 2026-08-28 玻璃胶囊与主题设计基础上增强插件页浮动导航的静态立体层次，不改写历史规格。Hub、封面、路由、主题存储、插件资料、保存协议和服务器 API 不变。

## 光学层次

胶囊继续由独立玻璃层处理真实页面背景折射，品牌、菜单和操作按钮保留在未滤镜处理的前景层。立体效果不使用透视变换、鼠标跟随或持续动画，而由三组固定光照构成：上方与左侧高光表达迎光面，下方与右侧 2–3px 内缘表达玻璃厚度，接触阴影与大范围柔和投影表达胶囊离开页面的悬浮距离。

深色主题使用冷白高光和深黑底缘，浅色主题使用亮白高光和蓝灰底缘。中心阅读区保持低对比装饰，避免降低文字和图标清晰度。静态厚边与投影不依赖背景 SVG 滤镜，因此减少动态效果、浏览器不支持折射或位移图生成失败时仍然存在；降级状态只取消背景位移。

玻璃层继续单独裁切圆角，Header 本身不裁切，主题面板和紧凑导航可以伸出胶囊。最大宽度、响应式网格、菜单字重、操作顺序及滚动显隐的 transform 均不改变。

## 验收方式

深色与浅色主题都以真实浏览器截图进行装饰开启与关闭的像素对照。上缘、下缘和胶囊外投影区必须出现独立差异，中心差异应低于最强边缘；菜单链接的几何位置必须完全相同。组件测试继续确认玻璃层没有链接、按钮或导航元素，完整回归覆盖 1600、1120、1023、768、390 和 320px，确保弹层不被裁切、无横向溢出且折射与滚动行为不回归。
