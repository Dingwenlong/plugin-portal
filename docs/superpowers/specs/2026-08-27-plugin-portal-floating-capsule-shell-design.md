# Plugin Portal 浮动胶囊 Shell 设计

## 范围

本设计只替换 `/#/plugins/<pluginId>/...` 的导航表现：旧的固定左侧栏与独立页面标题栏由顶部浮动胶囊取代。封面 `/#/`、Hub `/#/hub`、插件公开快照、Prompt、流程、下载资料、路由结构和服务器 API 均保持不变。

本文件是既有“侧栏导航”视觉约定的后续说明，不改写历史设计文档。

## 桌面结构

浮动胶囊固定在视口顶部，正文只为其预留一次固定高度；胶囊显示或隐藏不推动正文。

- 左侧显示插件图标和名称，链接到当前插件的鸟瞰全景。
- 中间复用六个带图标页面入口，当前页只用文字、图标和下划线状态表达，不增加矩形外框。
- 右侧依次显示下载入口和当前页面操作。Prompt、流程编辑器仍拥有自己的弹窗、草稿、保存错误和焦点恢复逻辑，只将触发按钮投射到胶囊操作区。
- 页面不再渲染独立可见的 `h1`；`main` 使用当前页面名称提供无障碍名称。

## 滚动状态

滚动监听使用被动事件和 `requestAnimationFrame` 合并更新。

- 页面顶部 24px 内始终显示。
- 同一方向向下累计 48px 后隐藏；向上累计 24px 后恢复。
- 改变方向时清空另一方向累计值。
- 路由切换、窄屏菜单展开、胶囊内部持有键盘焦点或 Portal 模态框打开时强制显示。
- `prefers-reduced-motion` 仅取消位移动画，不改变最终显示或隐藏状态。

## 紧凑布局

视口窄于 900px 时，左侧只保留插件图标，中间显示当前页面图标和名称，右侧保留下载、页面操作与“更多”按钮。“更多”展开同一套六项导航，并支持 Escape、点击外部、选择后关闭及焦点返回。

更窄视口允许操作按钮隐藏可见文字，但按钮继续提供完整 `aria-label` 和 `title`。最小支持宽度为 320px，页面不得出现横向溢出。

## 不变契约

- 不增加或修改插件公开资料字段。
- 不改变 Prompt、Workflow、插件快照和下载信息的数据结构、持久化接口或 revision 冲突处理。
- 不改变各页面业务组件对弹窗、表单、保存失败和焦点恢复的所有权。
- 不改变封面 Canvas、Start 转场和 Hub 的路由或交互。
