# Plugin Portal 浮动胶囊 Shell 设计

## 范围

本设计只替换 `/#/plugins/<pluginId>/...` 的导航表现：旧的固定左侧栏与独立页面标题栏由顶部浮动胶囊取代。封面 `/#/`、Hub `/#/hub`、插件公开快照、Prompt、流程、下载资料、路由结构和服务器 API 均保持不变。

本文件是既有“侧栏导航”视觉约定的后续说明，不改写历史设计文档。

## 桌面结构

浮动胶囊固定在视口顶部，最大宽度为 1440px 并居中；正文只为其预留一次固定高度，胶囊显示或隐藏不推动正文。仅插件页在根元素使用 `scrollbar-gutter: stable both-edges` 预留对称滚动条空间，长短页面切换不会改变胶囊横向位置或宽度；封面与 Hub 不预留。插件页正文允许收缩到扣除滚动条后的可用宽度，保证 320px 视口不横向溢出。

- 左侧显示插件图标和名称，链接到当前插件的鸟瞰全景。
- 中间复用六个带图标页面入口，两侧使用等宽轨道，确保页面操作增减不改变导航中心位置。所有菜单固定字重 600，选中时只改变文字及图标颜色与底线状态，不改变菜单宽度。当前页只保留菜单底部一条线，不增加文字下划线或矩形外框；键盘焦点使用同一底线的加粗状态。
- 右侧先显示当前页面操作，下载入口始终最右。操作按钮以下载按钮为基准统一字号、间距、边框与高度。Prompt、流程编辑器仍拥有自己的弹窗、草稿、保存错误和焦点恢复逻辑，只将触发按钮投射到胶囊操作区。
- 页面不再渲染独立可见的 `h1`；`main` 使用当前页面名称提供无障碍名称。

## 滚动状态

滚动监听使用被动事件和 `requestAnimationFrame` 合并更新。

- 页面顶部 24px 内始终显示。
- 同一方向向下累计 24px 后隐藏；向上累计 24px 后恢复。
- 改变方向时清空另一方向累计值。
- 路由切换、窄屏菜单展开、胶囊内部持有键盘焦点或 Portal 模态框打开时强制显示。
- 通过实际键盘和指针事件区分键盘焦点与鼠标点击残留焦点，不依赖浏览器可能持续保留的 `:focus-visible` 状态。鼠标切换路由或流程 Tab 后继续正常滚动，无需刷新；规则适用于全部插件页面。
- `prefers-reduced-motion` 仅取消位移动画，不改变最终显示或隐藏状态。

## 紧凑布局

视口窄于 900px 时，左侧只保留插件图标，中间显示当前页面图标和名称，右侧依次保留“更多”、页面操作与下载按钮。操作区预留固定宽度，避免页面操作变化挤动当前页面名称。“更多”展开同一套六项导航，并支持 Escape、点击外部、选择后关闭及焦点返回。

视口窄于 1280px 时操作按钮隐藏可见文字，但按钮继续提供完整 `aria-label` 和 `title`。最小支持宽度为 320px，页面不得出现横向溢出。

## 不变契约

- 不增加或修改插件公开资料字段。
- 不改变 Prompt、Workflow、插件快照和下载信息的数据结构、持久化接口或 revision 冲突处理。
- 不改变各页面业务组件对弹窗、表单、保存失败和焦点恢复的所有权。
- 不改变封面 Canvas、Start 转场和 Hub 的路由或交互。
