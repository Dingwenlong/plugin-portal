# Plugin Portal 全局无边框视觉补充设计

## 范围

本补充移除 Hub、插件内容页、表单、流程编辑器及弹层中的常规边框与分隔线。它只调整视觉层级，不改变路由、主题存储、插件资料、下载协议或服务器 API，也不影响封面与 Start 转场。

唯一保留的实体边缘是 `.portal-capsule` 的玻璃光学厚边。导航选中项继续使用单条底部指示线；键盘焦点继续提供高对比光晕，这两者属于状态反馈，不作为内容分隔线使用。

## 层级规则

- 按钮、输入框、选择框、文本框与 Fieldset 使用零边框和浅层主题色块；Header 操作默认透明，交互时才出现柔和底色。
- 表格、内容列表、Hub 插件条目和下载预览依靠行间距、圆角色块与悬停色区分，不再绘制横向分隔线。
- 流程 Tab、步骤卡片、画布、属性栏和新增入口通过背景明度与区域留白建立层次。
- 弹窗、主题面板和窄屏导航以不透明背景及柔和投影悬浮，不使用外框。
- 浏览器原生 Button、Input、Select、Textarea 与 Fieldset 统一清除默认边框，避免平台样式回流。

## 状态与可访问性

鼠标悬停、按下、禁用及选中状态均通过颜色或透明度表达。键盘焦点采用不参与布局的 `box-shadow` 光晕；Header 菜单仍以既有伪元素绘制选中底线，避免字重变化导致跳动。

## 验收

E2E 在深浅主题及桌面到 320px 的响应式宽度上扫描可见元素的计算样式：除 `.portal-capsule` 外，四边宽度必须全部为 `0px`。同时回归 Header 折射与雾化、菜单选中线、键盘焦点、弹层层级、横向溢出和封面进入 Hub 的转场。
