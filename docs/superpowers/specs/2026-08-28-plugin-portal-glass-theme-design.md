# Plugin Portal 玻璃胶囊与主题设计

## 范围与后续约定

本设计在已确认的浮动胶囊 Shell 上增加玻璃材质及深浅主题，替代旧设计中的胶囊材质、主题入口与紧凑断点约定，不改写历史文档。

主题覆盖 Hub、全部插件页面、加载与错误界面、Prompt 和流程弹窗、插件纳入弹窗。封面原作背景、Start 按钮、加载遮罩和进入 Hub 的转场保持原有深色表现，不随主题改变。插件公开资料、用户数据、下载目标、路由、保存协议和服务器 API 不变。

## 玻璃层

胶囊的光学表面独立放在品牌、菜单、按钮下方，使用 SVG 背景位移处理真实页面背景。位移集中于圆角边缘，中心保持中性；三条轻微不同的 RGB 位移合成边缘色散，高光与内侧阴影表达边缘厚度。这是二维背景折射，不声称三维物理光线追踪。

只有玻璃表面裁切圆角，header 本身不裁切，确保主题下拉和窄屏菜单可伸出胶囊。前景内容不经过滤镜，继续提供原有链接、按钮、焦点提示和点击区域。

位移图在首次测量和尺寸变化时生成，按尺寸最多缓存六份。ResizeObserver 通知通过单次 requestAnimationFrame 合并；滚动、切换主题和切换同尺寸页面不重新生成位移图，没有持续 JavaScript 动画循环。卸载时断开观察器、移除媒体查询监听并取消待执行帧；短生命周期画布不挂入 DOM，不使用对象 URL 或远端资源。

Chrome/Edge 且背景 SVG 滤镜与尺寸观察可用时启用折射。其他浏览器、减少动态效果或位移图生成失败时使用清透模糊玻璃；不能因装饰初始化失败阻断导航。浏览器仍存在背景 SVG 滤镜兼容差异，参见 [WebKit issue 245510](https://bugs.webkit.org/show_bug.cgi?id=245510)。

## 主题

默认深色。浅色使用白底、近黑正文、深灰辅助文字、轻量分隔线，并统一表格、表单、按钮、流程卡片、选中态、弹窗、窄屏导航和滚动条预留区域的变量。图标与插件图片不进行全局反色。

主题以 `plugin-portal.theme` 保存到浏览器 localStorage，值仅为 `dark` 或 `light`；无值或非法值回退深色，存储不可用仍可在当前页面切换。同一浏览器源下的所有插件共享设置，其他标签页的设置变化同步生效；不同协议、主机或端口遵循浏览器存储隔离，不承诺跨源同步。

主题仅改变上下文状态及根元素属性，不重建业务页面或编辑器，不改草稿、revision、滚动位置或焦点。只读访问同样允许切换主题。

## 入口与响应式

根据最新确认，下载按钮可见文案仅保留下载图标与版本号，例如 `v3.7.17`；完整“下载最新版”说明仍保留在 aria-label 和 title。原页面操作按钮的业务文案不变。

桌面操作区从左到右为页面操作、下载、三角入口。最右侧三角用于打开“主题设置”，主题切换默认不渲染；打开后不改变胶囊或中央菜单几何尺寸，支持再次点击关闭、点击外部关闭及 Escape 关闭并返回焦点。面板打开时胶囊保持显示。此顺序替代旧设计“下载为绝对最右控件”的约定，下载仍位于页面操作之后。

窄于 1024px 时进入紧凑布局：品牌仅显示图标，中央显示当前页面，右侧保留主题图标、更多导航、页面操作与下载；极窄屏中央仅显示图标，主区域保留完整无障碍页面名称。窄屏菜单复用六项导航，选择或 Escape 后返回“更多”按钮焦点，不裁切、不横向溢出，最小支持 320px。

Hub 的主题入口位于“纳入插件”左侧；只读访问隐藏纳入入口但保留主题切换。胶囊最大宽度 1440px、两侧等宽轨道、固定菜单字重和单条选中底线不变。全部插件页继续使用向下与向上各 24px 的滚动显隐，顶部、路由切换、键盘焦点和模态框状态继续保持原有约定。

## 验证与交付边界

组件测试覆盖主题存储与异常、跨标签同步、草稿和焦点保持、玻璃降级、尺寸缓存、资源清理及三角入口。真实浏览器以高对比页面文字与棋盘图形滚过胶囊后方，比较启用与禁用位移的像素：边缘发生位移、中心基本不变、导航前景字形不变。不能仅以滤镜 CSS 存在证明折射有效。

Chromium/Edge 验证两种主题、所有页面及弹窗、只读模式、加载与错误状态，以及 1600、1120、1024、1023、768、390、320px 布局。完整回归包括 Vitest、TypeScript、Python、隔离 Vite 构建和 Playwright；封面及转场继续执行现有回归。

本批只实现源码和隔离验证，保留既有 HTTPS 与 Hub 图标改动，不提交、不推送、不发布、不重启服务，也不操作 9136。构建与浏览器产物使用系统临时目录，测试服务使用操作系统分配的临时端口。
